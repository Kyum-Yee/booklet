# booklet — 나만의 시험지·교재 제작기

> **"글로 쓴 문제를 단 1초 만에 진짜 시험지와 문제집 PDF로 바꿔 드립니다."**  
> 복잡한 설치나 외부 서버 로그인 없이, 내 컴퓨터 로컬 서버(`http://localhost:8765`)에서 안전하고 강력하게 동작합니다.

---

## 💡 booklet은 어떤 도구인가요?

선생님, 강사님, 학부모님, 수험생 여러분이 메모장이나 AI(ChatGPT, Claude)로 만든 문제 글을 **수능 시험지나 학원 교재 스타일로 깔끔하게 정리해 인쇄용 PDF로 뽑아 주는 무료 도구**입니다.

- 📄 **수능 시험지 느낌 그대로**: 2단 시험지, 문제 번호, 지문 상자, `<보기>` 박스, ①~⑤ 선지까지 자동으로 배치됩니다.
- 🖨️ **인쇄 맞춤형**: A4나 B4 시험지 규격에 맞춰 페이지가 자동으로 나뉘며, 버튼 한 번으로 PDF 저장이 가능합니다.
- 🔒 **완벽한 개인정보 보호**: 내가 올린 문제와 파일이 외부 서버로 전송되지 않고 내 컴퓨터 로컬(`localhost`) 안에서만 안전하게 동작합니다.

## 💻 처음 시작하기: 내 컴퓨터에 셋업하기 (Windows / Mac)

> 💡 **"개발자 도구가 아무것도 안 깔려 있는 완전한 순정 PC여도 괜찮습니다!"**  
> 터미널이나 명령어 창을 다뤄본 적이 없어도 아래 순서대로 따라 하시면 2분 안에 바로 실행할 수 있습니다.

---

### 0단계: 파이썬(Python) 1분 무료 설치 (최초 1회만)

booklet 로컬 서버(`http://localhost:8765`)를 구동하려면 컴퓨터에 **Python(파이썬)**이 필요합니다.  
*(이미 컴퓨터에 파이썬이 깔려 있다면 곧바로 1단계로 넘어가세요!)*

#### 🪟 Windows (윈도우) 사용자
- **방법 A (가장 추천 - 클릭 한 번으로 끝!)**:
  1. 윈도우 시작 버튼을 누르고 **`Microsoft Store` (마이크로소프트 스토어)** 앱을 엽니다.
  2. 검색창에 **`Python`**을 검색하고, 최신 버전(예: **Python 3.12**)의 무료 **[받기 / 설치]** 단추를 누릅니다.
  3. 다운로드가 완료되면 설치 끝입니다! (복잡한 환경 변수나 개발자 설정이 자동으로 완료됩니다)
- **방법 B (공식 사이트 이용 시 주의사항!)**:
  1. [파이썬 공식 사이트 (python.org/downloads)](https://www.python.org/downloads/)에 접속하여 노란색 **[Download Python]** 버튼을 클릭합니다.
  2. 다운로드된 설치 파일(`.exe`)을 실행할 때, **설치 첫 화면 맨 아래에 있는 `☑️ Add python.exe to PATH` 체크박스에 반드시 체크**한 후 [Install Now]를 누르세요! *(이 체크박스를 체크하지 않으면 컴퓨터가 파이썬을 찾지 못합니다)*

#### 🍎 Mac (macOS) 사용자
1. [파이썬 공식 사이트 (python.org/downloads)](https://www.python.org/downloads/)에 접속합니다.
2. macOS용 최신 설치 패키지(`.pkg`)를 다운로드합니다.
3. 다운로드된 파일을 더블 클릭하고 안내 창에서 **[계속]** ➡️ **[설치]**만 누르시면 자동으로 완벽하게 설치됩니다.

---

### 1단계: booklet 다운로드 및 압축 풀기

1. 이 깃허브 저장소 화면 오른쪽 위의 초록색 **[<> Code]** 버튼을 누르고 **[Download ZIP]**을 클릭합니다.  
   *(Git을 쓸 줄 아신다면 `git clone https://github.com/Kyum-Yee/booklet.git`)*
2. 다운로드된 `booklet-main.zip` 파일 위에서 마우스 우클릭 ➡️ **[압축 풀기]**(Mac은 더블 클릭)를 하여 폴더를 엽니다.

---

### 2단계: 더블 클릭 한 번으로 실행하기 (원클릭 실행!)

터미널이나 명령어를 칠 필요 없이, 압축이 풀린 `booklet` 폴더 안의 **전용 실행 파일**을 더블 클릭하기만 하면 끝납니다!

- **🪟 Windows 사용자**:  
  폴더 안의 **`start_windows.bat`** 파일을 더블 클릭합니다.  
  *(잠시 검은 창이 뜨면서 자동으로 로컬 서버가 켜지고 웹 브라우저가 열립니다)*
- **🍎 Mac 사용자**:  
  폴더 안의 **`start_mac.command`** 파일을 더블 클릭합니다.  
  *(자동으로 로컬 서버가 구동되고 브라우저가 열립니다)*

> [!NOTE]  
> **터미널을 직접 이용하고 싶으신 분들을 위한 명령어:**
> - Windows: 폴더 내에서 터미널을 열고 `python booklet.py serve` (또는 `py booklet.py serve`)
> - Mac: 터미널에서 `python3 booklet.py serve`
> - 접속 주소: `http://localhost:8765`

## 🚀 가장 쉬운 사용법 3단계

### 1단계: booklet 열기
위 2단계 실행 파일을 더블 클릭하면 웹 브라우저(크롬, 엣지, 사파리 등)가 열리며 `http://localhost:8765` 화면이 바로 나타납니다.
*(서버 창이 켜져 있는 동안 시험지를 조판할 수 있습니다)*

### 2단계: 문제 파일 끌어다 놓기
문제가 적힌 마크다운(`.md`)이나 텍스트(`.txt`) 파일을 화면 가운데 **[파일·폴더를 여기에 놓으세요]** 공간에 마우스로 쓱 끌어다 놓습니다(드래그 앤 드롭).

### 3단계: [인쇄] 누르고 PDF 저장하기
화면 오른쪽 위에 있는 파란색 **[인쇄]** 단추를 누르면 끝!  
인쇄 창에서 대상 프린터를 **'PDF로 저장'**으로 선택하시면 깨끗한 시험지 PDF가 내 컴퓨터에 저장됩니다.

## 🤖 ChatGPT / Claude '프로젝트'에 넣고 문제 무제한 만들기

ChatGPT(유료)나 Claude의 **프로젝트(Project)** 기능에 `booklet`을 넣어 두면, AI가 알아서 booklet에 100% 호환되는 완벽한 시험지 형식으로 문제를 만들어 줍니다.

### ① AI 프로젝트에 등록하기 (최초 1회)
1. **Claude** 또는 **ChatGPT**에 접속하여 **[새 프로젝트 만들기(Create Project)]**를 누릅니다.
2. 프로젝트 이름은 `나만의 문제 출제기` 등으로 짓습니다.
3. 프로젝트의 **[지식(Project Knowledge)]** 또는 파일 첨부 공간에 **`booklet` 폴더 안의 파일들(특히 `format.md` 파일)**을 통째로 올립니다.

---

### ② AI에게 요청하는 마법의 주문 (그대로 복사해서 쓰세요!)

프로젝트 채팅창에 아래 문장을 복사해서 원하는 과목과 단원만 바꿔 물어보세요:

```text
내가 올려둔 booklet 양식(format.md의 batch 포맷)을 엄격하게 지켜서 문제를 출제해줘.

1. 과목: 국어 (문법)
2. 대상: 고등학교 2학년
3. 단원: 품사 통용과 올바른 맞춤법
4. 문항 수: 3문항 (오지선다 객관식)
5. 필수 포함 사항:
   - 각 문제마다 [문제], 문항 번호와 권장 시간 (예: 1 (2분))
   - 지문은 따옴표 세 개(""" ... """)로 감싸기
   - 보기 상자는 <보기> 로 감싸고 내부 항목은 ㄱ., ㄴ., ㄷ. 표기
   - 선지는 반드시 줄 첫머리에 ①, ②, ③, ④, ⑤ 기호 사용
   - 문제 끝마다 [해설], [풀이], [정답] n 정확히 기재
   - 문제와 문제 사이는 --- 단독 줄로 구분

출제한 문제 전체를 메모장에 바로 붙여넣을 수 있게 마크다운 형식으로 한 번에 써줘.
```

---

### ③ AI 답변을 시험지로 만들기
1. AI가 작성해 준 답변 내용을 복사합니다.
2. 내 컴퓨터 메모장(또는 텍스트 편집기)을 열어 붙여넣고 `문제.md` 또는 `문제.txt` 파일로 저장합니다.
3. 저장한 파일을 열려 있는 booklet 화면으로 쓱 끌어다 놓으면 즉시 조판된 시험지가 눈앞에 나타납니다!

## 🎨 내 마음에 쏙 들게 시험지 꾸미기

왼쪽 사이드바 메뉴에서 마우스 클릭 몇 번으로 시험지를 자유롭게 바꿀 수 있습니다:

- **용지 및 배치**:
  - **수능 시험지 스타일**: 모의고사 2단 시험지 (`2×1`)
  - **학원 교재 스타일**: 널찍한 1단 교재 (`1×1`)
  - **수학 프린트 스타일**: 위아래 2칸 (`1×2`)
  - B4 모의고사 시험지 또는 A4 일반 용지 선택 가능
- **문서 정보 입력**:
  - 제목(예: *2026학년도 3월 학력평가 대비*), 부제, 과목, 학원 이름, 회차 등을 입력하면 시험지 상단 헤더에 자동으로 인쇄됩니다.
- **정답표 & 빠른 정답 시트**:
  - 빠른 정답표 모아보기, 상세 해설집 분리 인쇄, 표지 자동 생성 기능도 켜고 끌 수 있습니다.

## 📌 유용한 팁 & 자주 묻는 질문

- **창을 닫으면 작업하던 게 날아가나요?**  
  아닙니다! 브라우저가 자동으로 작업 내용을 기억하므로, 창을 닫았다가 다시 열어도 방금 작업하던 상태 그대로 이어집니다.
- **완전히 처음 상태로 비우고 싶어요.**  
  왼쪽 메뉴 맨 아래 **[내보내기]** 탭에서 빨간색 **[프로젝트 초기화]** 버튼을 누르시면 새 도화지로 리셋됩니다.
- **수식이나 표도 잘 나오나요?**  
  네! `$x^2 + y^2 = r^2$` 같은 수학 수식, 화학식, 마크다운 표, 아스키 아트로 그린 회로도/도형까지 모두 선명하게 지원합니다.
- **[선택/CLI] 로컬 서버를 안 띄우고 한 줄로 바로 PDF를 뽑거나 단일 HTML 파일로 만들 수 있나요?**  
  네! 터미널이나 파이썬에 익숙한 분들을 위해 브라우저나 웹 서버를 켜지 않고도 바로 처리하는 CLI 명령어(`build`)를 지원합니다:
  - `python booklet.py build 문제.md --pdf 시험지.pdf` : 브라우저 없이 파이썬이 알아서 PDF로 바로 변환해 줍니다.
  - `python booklet.py build 문제.md -o 내시험지.html` : 문제가 이미 들어간 단일 HTML 파일이 생성되며, 로컬 서버 없이 파일 더블 클릭(`file:///`)만으로 열어 바로 편집할 수 있습니다.  
  *(※ 대량 배치 처리용 대체 경로이며, 화면을 보며 실시간으로 편집하는 정석 루트는 로컬 서버 실행입니다. 자세한 옵션은 [TECH_README.md](./TECH_README.md)를 참고하세요.)*
